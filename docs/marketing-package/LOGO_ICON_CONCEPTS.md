# Logo And Icon Concepts

## Umbrella Logo Concept

Direction: a compact `TW` monogram in an ink square with a restrained technical feel.

Current prototype asset:

- `../../public/favicon.svg`

Concept attributes:

- Shape: 1:1 mark with 14px corner radius at 64px.
- Lettering: uppercase `TW`, bold, geometric, readable at favicon size.
- Color: Ink base with white and Trust Teal/Signal Blue letter accents.
- Use: favicon, browser tab, app launcher placeholder, deck cover, footer stamp.

Full lockup direction:

- TW mark left.
- "Technowiz Solutions" wordmark right.
- Use Ink text on white/canvas backgrounds.
- Clear space: at least half the mark width around the lockup.

Do not:

- Use gradients inside the initials.
- Stretch the mark.
- Use product initials for the umbrella brand.
- Place the mark on low-contrast backgrounds.

## Product Icon Concepts

### NoDupe

Concept: overlapping folders with one protected check mark.

Meaning:

- Multiple libraries and backups.
- One trusted master destination.
- Protected cleanup instead of blind deletion.

Recommended colors:

- Ink outline
- Trust Teal check
- Action Amber for review states

### PDF Compressor

Concept: document page with compression rails and a before/after split.

Meaning:

- PDF-specific utility.
- Smaller output.
- Preview-before-save confidence.

Recommended colors:

- Ink outline
- Signal Blue document compression cue
- Trust Teal preview/accepted state

## Icon System

Use these as the first umbrella icon set:

- Local device: desktop window with storage bar.
- Protected workflow: shield with check mark.
- Preview split: rectangular before/after pane.
- Audit trail: document list with export/check marker.
- Recover: clockwise restore arrow.
- Explain: document with highlighted recommendation line.

Production rules:

- 24px grid.
- 2px stroke.
- Rounded joins/caps.
- 8px radius only when an icon needs a container.
- No internal shadows.
- No decorative-only icons on product pages.

## Website Placement

Use umbrella icons for:

- Homepage trust strip.
- Services section.
- Enterprise/support proof rows.

Use product icons for:

- Product cards.
- Product detail headers.
- Download/pricing pages.
- Social cards.
