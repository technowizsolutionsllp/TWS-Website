## External Website Boundary

The brand guidelines are internal and should not be exposed as a public route. The public website should only show customer-facing pages: homepage, product pages, services, contact, legal/support pages, and future pricing or download pages.

## Brand Summary

Technowiz Solutions is a modern product engineering company for local-first software and IT-enabled services. The customer-facing promise is simple:

> Local-first software for high-trust file decisions.

The first product stories are:

- NoDupe: safe consolidation of duplicate and copied files into one trusted library.
- PDF Compressor: private, local PDF compression with analysis and real preview before saving.
