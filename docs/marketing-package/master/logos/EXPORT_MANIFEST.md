# Technowiz R2 Export Package

Selected direction: R2 from the Rishi Node family.

All SVG exports in this folder have transparent backgrounds unless the filename says `preview`.

## Umbrella Brand

- `technowiz-r2-mark-light.svg`  
  Transparent mark for white, canvas, or other light backgrounds.

- `technowiz-r2-mark-dark.svg`  
  Transparent mark for ink, dark, or image backgrounds.

- `technowiz-r2-lockup-light.svg`  
  Transparent full lockup for light backgrounds.

- `technowiz-r2-lockup-dark.svg`  
  Transparent full lockup for dark backgrounds.

## Product App Logos

- `nodupe-r2-app-logo-light.svg`  
  Transparent NoDupe app logo for light backgrounds.

- `nodupe-r2-app-logo-dark.svg`  
  Transparent NoDupe app logo for dark backgrounds.

- `pdf-compressor-r2-app-logo-light.svg`  
  Transparent PDF Compressor app logo for light backgrounds.

- `pdf-compressor-r2-app-logo-dark.svg`  
  Transparent PDF Compressor app logo for dark backgrounds.

## Preview

- `r2-export-preview.svg`  
  Preview sheet only. Contains background panels to show how the transparent exports behave on light and dark surfaces.

## Notes

- The mark uses a shirorekha-like top bar, central guide stem, knowledge spark, and connected nodes.
- The product icons reuse the same spark/node language so NoDupe and PDF Compressor feel part of one product family.
- For app-store/installer icon generation, export these SVGs to PNG/ICO sizes after the final direction is approved.
